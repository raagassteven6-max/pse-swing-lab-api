How EODHD Works

EODHD provides real end-of-day stock data for exchanges worldwide, including the Philippine Stock Exchange (PSE).

PSE ticker format: Add .XPHS suffix, e.g., BDO.XPHS, GLO.XPHS

Free plan: 20 API calls/day, past year of historical data only.

Paid plans: Starting at ~$19.99/month for unlimited calls and full history.

Data update: PSE data updates 2-3 hours after market close (around 5:45 PM PST).

⚡
Setup Steps
  1. Sign up at eodhd.com (free plan available)
  2. Copy your API key from the dashboard
  3. Paste it in the API Key field above
  4. Set date range (free plan = past year only)
  5. Switch to EODHD Live mode
  6. Load any stock — real PSE data appears!
✅ No Google Sheets Needed
Data flows directly from EODHD to your browser. No Sheets, no scripts, no deployment.

// EODHD API call for BDO historical data https://eodhd.com/api/eod/BDO.XPHS?api_token=YOUR_KEY&from=2025-07-01&to=2026-07-23&period=d&fmt=json // Response format: [ { "date": "2026-07-22", "open": 145.20, "high": 147.50, "low": 144.80, "close": 146.30, "adjusted_close": 146.30, "volume": 1250000 } ]
